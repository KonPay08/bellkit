# 機能仕様書

## 1. 概要

Bellkit は通常文（ひらがな・カタカナ）とベル文字（数字列）を双方向に変換する単ページWebアプリである。
標準ポケベルの2タッチ式に準拠した符号化方式を採用する。
UIはDeepLモバイル版を踏襲し、入力するとリアルタイムで変換される。

関連ドキュメント:
- `requirement.md` — 要件定義
- `docs/conversion-table.md` — 変換表

## 2. 画面構成

スマホをメインデバイスとし、縦1カラムで構成する。

**入力前（初期状態）:**

```
┌─────────────────────────────┐
│  [ 通常文 ]  ⇄  [ ベル文字 ] │  ← 方向表示 + 切替ボタン
├─────────────────────────────┤
│                             │
│  ひらがな・カタカナを入力     │  ← 入力エリアのみ表示
│                             │
└─────────────────────────────┘
  ※ 難読化であり暗号ではありません    ← フッター注意書き
```

**入力後（出力エリア出現）:**

```
┌─────────────────────────────┐
│  [ 通常文 ]  ⇄  [ ベル文字 ] │  ← 方向表示 + 切替ボタン
├─────────────────────────────┤
│                          ✕  │
│  こんにちは                  │  ← 入力エリア（編集可能）
│                             │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┤  ← 区切り線
│                             │
│  2503524241               📋 │  ← 出力エリア（読み取り専用）
│              [なし|スペース]  │  ← 区切りトグル（条件付き表示）
├─────────────────────────────┤
│  (エラー表示)                │  ← 条件付き
└─────────────────────────────┘
  ※ 難読化であり暗号ではありません    ← フッター注意書き
```

入力エリアと出力エリアは1つのカード内に上下で配置し、薄い区切り線で分ける。
出力エリアは入力が空のときは非表示、テキストが入力されると出現する。

### 2.1 方向表示

- カード上部に「通常文」と「ベル文字」のラベルを表示
- 中央に ⇄ ボタンを配置
- 現在の入力側のラベルが左、出力側が右

### 2.2 入力エリア

- 編集可能なテキストエリア
- 右上に ✕（クリア）アイコンボタン。入力が空のときは非表示
- プレースホルダーはモードに応じて切り替わる
  - 通常文→ベル文字: 「ひらがな・カタカナを入力」
  - ベル文字→通常文: 「数字列を入力」

### 2.3 出力エリア

- 読み取り専用
- 右上に 📋（コピー）アイコンボタン。出力が空のときは非表示
- ベル文字出力時は等幅フォント

### 2.4 区切りトグル

- 「通常文→ベル文字」モード時のみ出力エリア内に表示
- 「なし」「スペース」の2択トグル
- 初期値: 「なし」
- 切り替えると即座に出力が更新される

### 2.5 注意書き

- カード下部に小さく表示
- 「※ これは暗号化ではなく難読化です。重要情報のやりとりには使わないでください」

## 3. 機能詳細

### 3.1 リアルタイム変換

**トリガー:** 入力エリアへのテキスト入力（キー入力のたび）

**通常文→ベル文字モード:**

1. 入力テキストを正規化（§4参照）
2. 正規化後の各文字を変換表で2桁コードに変換
3. 区切り設定に従ってコードを連結
4. 結果を出力エリアに表示

**ベル文字→通常文モード:**

1. スペースを除去して数字列のみにする
2. 入力検証（§3.1.1参照）
3. 2桁ずつ区切って変換表を逆引き
4. 濁点・半濁点記号を前の文字と合成（§4.4参照）
5. 結果を出力エリアにカタカナで表示

**成功時:**
- 出力エリアに結果を表示
- エラー表示はクリア

**失敗時:**
- 出力エリアは空にする
- エラーメッセージを表示

#### 3.1.1 エラー条件

**通常文→ベル文字:**

| 条件 | メッセージ |
|------|-----------|
| 未対応文字 | `{N}文字目「{文字}」は未対応です` |

**ベル文字→通常文:**

| 条件 | メッセージ |
|------|-----------|
| 数字以外の文字を含む | `位置 {N} のコード「{文字}」が不正です` |
| 桁数が奇数 | `位置 {N} のコード「{文字}」が不正です` |
| 変換表に存在しない2桁コード | `位置 {N} のコード「{コード}」が不正です` |

### 3.2 方向切替（⇄）

**トリガー:** ⇄ アイコンボタン押下

1. 変換方向を切り替える（通常文→ベル文字 ⇔ ベル文字→通常文）
2. 出力エリアの内容を入力エリアに移動する
3. 出力エリアを空にする
4. 移動した内容で即座にリアルタイム変換を実行する
5. エラー表示はクリア

**状態変化の例:**

```
変換前:  入力「あいう」 → 出力「111213」（通常文→ベル文字モード）
⇄ 押下後: 入力「111213」 → 出力「アイウ」（ベル文字→通常文モード）
```

### 3.3 クリア（✕）

**トリガー:** ✕ アイコンボタン押下

- 入力エリアを空にする
- 出力エリアも連動して空になる
- エラー表示もクリア

### 3.4 コピー（📋）

**トリガー:** 📋 アイコンボタン押下

- 出力エリアの内容をクリップボードにコピー
- 成功時: トースト通知「コピーしました」を2秒間表示
- 失敗時: エラーメッセージ「コピーに失敗しました」

### 3.5 区切りトグル

- 「通常文→ベル文字」モード時のみ表示
- 「なし」と「スペース」を切り替えると出力が即座に更新される
- 「ベル文字→通常文」モードでは非表示（入力のスペース有無は自動判別）

**入出力例（通常文→ベル文字）:**

| 入力 | 区切り | 出力 |
|------|--------|------|
| アイウ | なし | `111213` |
| アイウ | スペース | `11 12 13` |
| あいう | なし | `111213` |
| ガンバレ | なし | `210403610494` |
| パン | なし | `610503` |
| ッツ | なし | `4343` |
| ア漢字 | — | エラー: `2文字目「漢」は未対応です` |

**入出力例（ベル文字→通常文）:**

| 入力 | 出力 |
|------|------|
| `111213` | アイウ |
| `11 12 13` | アイウ |
| `2104` | ガ |
| `210403610494` | ガンバレ |
| `1` | エラー（奇数桁） |
| `99` | エラー（未知コード） |

## 4. 正規化ルール

変換時（通常文→ベル文字）に入力テキストを正規化する。

### 4.1 ひらがな → カタカナ変換

Unicode のコードポイント差（+0x60）でカタカナに変換する。

| 入力 | 正規化後 |
|------|----------|
| あ → ア | い → イ | う → ウ |

### 4.2 小文字 → 大文字変換

以下の小文字カタカナを対応する大文字に変換する。

| 小文字 | 大文字 |
|--------|--------|
| ァィゥェォ | アイウエオ |
| ッ | ツ |
| ャュョ | ヤユヨ |
| ヮ | ワ |

### 4.3 濁音・半濁音の分解

濁音は清音＋゛（濁点記号）に分解する。半濁音は清音＋゜（半濁点記号）に分解する。

| 入力 | 分解結果 |
|------|----------|
| ガ | カ + ゛ |
| パ | ハ + ゜ |
| ヴ | ウ + ゛ |

### 4.4 復号時の再合成

復号時（ベル文字→通常文）は逆に、清音の直後に゛または゜が来た場合に合成する。

| 復号結果 | 合成後 |
|----------|--------|
| カ + ゛ | ガ |
| ハ + ゜ | パ |
| ウ + ゛ | ヴ |

合成できない組み合わせ（例: ア + ゛）の場合はそのまま出力する。

### 4.5 処理順序

正規化は以下の順序で適用される:

1. ひらがな → カタカナ変換
2. 各文字に対して:
   - 濁音なら清音 + ゛ に分解
   - 半濁音なら清音 + ゜ に分解
   - 小文字なら大文字に変換
   - それ以外はそのまま

## 5. 未対応文字

以下は MVP で未対応であり、入力すると変換エラーとなる。

- 漢字
- 英字（A-Z, a-z）
- 数字（0-9）
- 記号（句読点、長音符ー、スペースなど）
- 絵文字

### 5.1 将来追加候補

- 数字 0〜9
- 記号（句読点、長音符、スペース）

## 6. エラー表示

- カード下部に赤い背景で表示
- 入力変更時に自動でクリアされる（リアルタイム変換のため）
- 同時に表示されるエラーは1件のみ（最初のエラーで処理を中止するため）

## 7. トースト通知

- 画面下部中央に表示
- 表示時間: 2秒で自動消滅
- フェードインアニメーション付き
