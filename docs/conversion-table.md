## 濁音・半濁音の扱い

分解方式を採用する。

- 濁音: 清音コード + ゛(04) で表す
  - 例: ガ = カ(21) + ゛(04) → `2104`
- 半濁音: 清音コード + ゜(05) で表す
  - 例: パ = ハ(61) + ゜(05) → `6105`
