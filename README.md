# Bellkit

通常文（ひらがな・カタカナ）とベル文字（数字列）を双方向に変換するWebアプリ。
標準ポケベルの2タッチ式に準拠。

## 使い方

1. テキストを入力するとリアルタイムで変換
2. コピーボタンで結果をクリップボードにコピー
3. ⇄ ボタンで変換方向を切り替え

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # ビルド
npm run test     # テスト実行
```

## 技術スタック

React + TypeScript (Vite) / Tailwind CSS v4 / Vitest
